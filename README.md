# Login Simulator 🔐

## About
A simple Python project that simulates a login system by checking a username and password against stored credentials.

## Features
- Checks whether the username exists.
- Verifies the password.
- Displays a login success or failure message.

## Concepts Used
- Python dictionaries
- User input
- `if-else` statements
- Logical operators (`and`)

## How to Run
1. Install Python 3.
2. Run the file:
python login_simulator.py

## What I Learned
I learned how to store usernames and passwords in a dictionary and verify login credentials using conditional statements.

## Status
Completed — beginner Python project.

**Note:** This is a learning project. Passwords are stored in plain text, so it is not suitable for real authentication.
